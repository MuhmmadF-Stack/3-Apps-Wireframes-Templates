# 3-Apps-Wireframes-Templates

Three fully interactive mobile app prototypes for food delivery, fitness tracking and personal budgeting. Each is a self-contained HTML file with light and dark modes and no build step.

1. An overview of the collection and who it's for
2. A full feature list for each app: Daily Dish (food delivery), Stride (fitness) and Pocket (budgeting)
3. Features shared by all three: dark mode, a separate look for each app, and sample data that stays consistent
4. How to clone, run locally and publish with GitHub Pages
5. How to change colors, sample data, promo codes and budget categories
6. Which browsers it works in, its limits as a front-end-only prototype, and the MIT license

How to upload:
Create a new repository at github.com/new.
Use Add file → Upload files, drag in everything from the zip, then commit.
For a live link, go to Settings → Pages, choose the main branch and / (root), then save.
